## Commit and Pull Request Titles Without Scope

**Impact: LOW**

Use `type: subject` for commit subjects and pull request titles in this project. Never include a scope, such as `docs(prd):`, so titles follow the repository's established format.

**Incorrect:**

```text
docs(prd): revise the portfolio audience and scope
```

**Correct:**

```text
docs: revise the portfolio audience and scope
```
