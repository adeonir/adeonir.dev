## O contexto

### Um servidor WordPress lento demais para o próprio site

A agência usava um tema tradicional de WordPress. Cada página era montada no servidor a cada acesso. A busca era lenta, mesmo com cache. Qualquer mudança no frontend exigia mexer na estrutura do conteúdo. Movi o site para uma arquitetura headless. O WordPress continua como CMS, atrás de uma API GraphQL, e as páginas são pré-renderizadas no build e regeneradas sob demanda. A busca passou para a Algolia, com filtros por categoria, e as imagens passaram para o proxy da ImageKit.

O servidor do WordPress era tão lento que a regeneração sob demanda das páginas falhava. Por isso a API GraphQL fica atrás de um proxy na Cloudflare, que responde a partir do cache. As páginas carregam 50% mais rápido no Lighthouse, e a busca na Algolia responde em menos de 100 ms. Todas as URLs continuaram válidas depois da migração, e o time de marketing publica conteúdo sem depender de desenvolvedor.
