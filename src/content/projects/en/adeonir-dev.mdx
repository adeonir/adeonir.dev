## The context

### A site built with the same care I put into every project

This site is my calling card, so it has to match the quality of my professional work. I built it in Astro, and it runs on Cloudflare. The home page is a one-page layout, with navigation between sections, smooth entrance animations, and a responsive design.

It is available in Portuguese and English, with light and dark themes. Every build runs unit tests and a Lighthouse audit before it ships. Those checks cover performance and accessibility.
